# ทะเบียนความเสี่ยง

ขอบเขต: ต้นแบบ React/TypeScript + localStorage + static deployment; ผู้รับผิดชอบ ระบุเป็นบทบาทที่ทีมต้องมอบหมายผู้รับผิดชอบจริง ไม่ใช่หลักฐาน contribution

## แนวทางติดตาม

ก่อนนำเสนอให้ ผู้รับผิดชอบ แต่ละคนอัปเดตวันที่และ URL หลักฐานใน PR/review record ไม่เปลี่ยนรายการ open เป็น closed เพียงเพราะเขียนแผนไว้ การยอมรับ คงเหลือ risk ของ ต้นแบบ ต้องแยกจากการอนุญาตใช้กับข้อมูลจริง หากมีการเพิ่ม บริการหลังบ้าน/QR/approval ให้ทบทวน DFD, misuse cases, requirements และ risk ใหม่
