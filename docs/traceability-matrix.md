## วิธีใช้ในวันนำเสนอ

เปิด FR-03 → สาธิตการจอง → เปิด `BookingService.save` → เปิดการทดสอบเวลาทับซ้อน/แก้ไข แล้วเชื่อมกับ T-01/R-01/SR-01 เพื่ออธิบายความสัมพันธ์ระหว่างความเสี่ยง ข้อกำหนด การออกแบบ โค้ด และหลักฐาน รายการที่ยังเป็นแผนต้องระบุว่าไม่อยู่ในขอบเขตที่เสร็จ ไม่ซ่อนออกจากตาราง
