# คำศัพท์และขอบเขตการใช้ภาษา

ข้อความหน้าจอ เอกสาร คำอธิบายโค้ด ชื่อกรณีทดสอบ และชื่อขั้นตอนที่ผู้ใช้เห็นใน CI/CD ใช้ภาษาไทย ส่วนชื่อที่ต้องตรงกับมาตรฐานหรือโค้ดจริงคงภาษาอังกฤษ

| คำที่คงไว้                                                              | ความหมายภาษาไทย / เหตุผล                                                                                     |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| React, TypeScript, Vite, Zustand, Radix, Motion, GitHub Pages           | ชื่อผลิตภัณฑ์หรือไลบรารี                                                                                     |
| SOLID, SRP, OCP, LSP, ISP, DIP                                          | ชื่อย่อมาตรฐานของหลักการออกแบบ พร้อมคำอธิบายไทยในเอกสารสถาปัตยกรรม                                           |
| DFD, STRIDE, CIA                                                        | ชื่อแบบจำลองและหมวดวิเคราะห์ความปลอดภัย                                                                      |
| CI/CD                                                                   | การตรวจรวมโค้ดและการติดตั้งอัตโนมัติ                                                                         |
| API, HTTP, HTTPS, JSON, HTML, CSS, DOM, MIME, URL, UTC, UTF-8, ICS, PWA | ชื่อมาตรฐาน โปรโตคอล หรือรูปแบบข้อมูล                                                                        |
| Wi-Fi, LCD, KMITL                                                       | ชื่อมาตรฐานอุปกรณ์และชื่อย่อสถาบัน                                                                           |
| class, interface, module, dependency injection                          | ศัพท์เทคนิคที่ใช้เทียบกับโค้ด โดยมีคำอธิบายภาษาไทยประกอบ                                                     |
| `BookingService`, `BookingRepository`, `validate`, `save`               | ชื่อคลาส/ฟังก์ชันจริง ไม่แปลตัวระบุในโปรแกรม                                                                 |
| `student`, `staff`, `admin`, `Projector`, `Computer`, `Microphone`      | รหัสภายในที่รักษาความเข้ากันได้ ป้ายบนหน้าจอแสดงภาษาไทย                                                      |
| ชื่อไฟล์ โฟลเดอร์ คำสั่ง และคีย์ข้อมูล                                  | รักษาการนำเข้าโค้ด การเรียกเครื่องมือ และข้อมูลเดิม เช่น `npm run build`, `localStorage`, `kmitl-booking-v1` |
| ชื่อห้องภาษาอังกฤษสำหรับค้นหา                                           | เก็บเป็นข้อมูลนามแฝงเพื่อรองรับการค้นหาไทย/อังกฤษ                                                            |
| ชื่อกรณีทดสอบด้านโปรโตคอลและข้อความจำลองเฉพาะทาง                        | เก็บข้อมูล ASCII/ข้อความโจมตีที่จำเป็นต่อการตรวจการเข้ารหัสและมาตรฐาน                                        |
| ประวัติ commit ชื่อผู้เขียน URL และไฟล์หลักฐานเดิม                      | เป็นบันทึกที่เกิดขึ้นจริง จึงไม่แก้ถ้อยคำย้อนหลังหรือแปลเนื้อหา JSON/ภาพหลักฐานเดิม                          |
| LICENSE และ HTML อ้างอิงที่ผู้ใช้ให้มา                                  | เป็นต้นฉบับสิทธิ์และข้อมูลอ้างอิง ไม่ดัดแปลงเป็นงานแปลของโครงงาน                                             |

การแปลไม่เปลี่ยนตรรกะการจอง ข้อมูลที่บันทึกไว้ รูปแบบไฟล์มาตรฐาน หรือขอบเขตความปลอดภัยของระบบ
